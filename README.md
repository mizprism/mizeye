# MizEye

**やさしい規約ビューア**

MizEye（ミズアイ）は、VRChat 向け商品の利用規約を Unity 上で確認するためのビューアです。
署名付きの公開フィードを読み取る read-only のツールで、プロジェクトを一切変更しません。

MizEye by MIZPRISM

## 何をするツールか

Unity プロジェクトの中の資産に、その商品の利用規約を紐づけて表示します。
「改変していいのか」「動画に使っていいのか」「収益化配信で使えるのか」を調べるときに、
商品ページと規約 PDF を行き来する代わりに、Unity の中で一覧できます。

## 何を返し、何を返さないか

**返すのは整理であって、判定ではありません。**

- 「この使い方は OK です」とは言いません。規約が何をどう定めているかを、項目ごとに並べます
- 規約に書かれていないことは **`unclear`（不明）として第一級で表示します**。空欄にも「情報なし」にもしません。
  「書かれていないと分かっている」という積極的な事実として出します
- 最終的な判断と責任は利用者にあります。迷う場合は権利者に確認してください

## v0.1 の範囲

**アバター素体を中心とした動作テスト版です。網羅性は主張しません。**

- 収録数: items 87 / terms 74（データ基準日 2026-08-18）
- 衣装・アクセサリーは今後
- 未収載の商品は「未収載」と表示します。推測で埋めることはしません
- 対応 Unity: 2022.3（VRChat 現行 LTS）
- 対応 OS: Windows / Linux。**macOS は対象外です**

## 導入

1. VCC の **Settings > Packages > Add Repository** に次の URL を追加します

   ```
   https://mizprism.github.io/mizeye/index.json
   ```

2. プロジェクトの **Manage Project** から **MizEye** を Add します
3. Unity で **Window > MIZPRISM > MizEye** を開きます

## フィードについて

規約データの正本は、署名付きの公開フィードです。

- 配信元: <https://feed.mizprism.workers.dev>
- **Ed25519 で署名されています。** 検証用の公開鍵はパッケージに同梱しています。
  署名検証に失敗したチャンクは破棄し、前回のキャッシュを保ちます（汚染されたデータを表示しません）
- 取得はエディタ起動時と手動で、**1 日 1 回まで**です
- フィードに到達できないときは、キャッシュを「最終取得: N 日前」付きで表示します
- **BOOTH へのリクエストは行いません。** 読むのは自前のフィードだけです
- テレメトリはありません。外部への送信はフィードの取得のみです

## 収載のリクエスト・誤りの報告

Issues へどうぞ。日本語で構いません。

規約の読み取りに誤りを見つけた場合は、**どの商品の・どの項目が・規約のどの記述と食い違うか**を
書いていただけると助かります。データは一次資料（規約本文）の直読みで作っており、
訂正も一次資料に当たって行います。
