# feed-cache fixture

データ層 (取得 → 署名検証 → キャッシュ → 差分検出) の回帰テスト用ミニチュアフィード。

- `v1/` = 最初の取得、`v2/` = 次の取得。v2 では **terms 1 本が改訂**され、
  **item が 1 件増えて shard `items/02.json` が新設**される (差分検出の真値)。
- `keyring.json` の鍵は**使い捨て**で、秘密鍵は生成直後に破棄済み。
  したがって**この fixture に新しい署名を足すことはできない** — 別の世代が要るなら
  鍵ごと作り直す (既存の署名も全て変わる)。本番鍵は同梱リング `FeedKeyringEmbedded.cs`。
- `index.json` は署名対象そのもの。**1 バイトも変えてはいけない**
  (`.gitattributes` の `tools/fixtures/** -text` が改行変換を止めている)。
- 書式はフィード生成器 (非公開の収集パイプライン) の `canon_bytes` と同一
  (キー順固定 / 非 ASCII をエスケープしない / indent=1 / 末尾改行)。
