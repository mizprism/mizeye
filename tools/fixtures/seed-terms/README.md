# seed-terms — シードレコードの凍結スナップショット

MizEye が実際に配信している terms レコードのうち 4 本を、**シード形のまま**凍結したもの。
パーサとビューの振る舞いを「作り物ではない形」で測るための fixture。

| stem | 何のレコードか | 何を測るのに使うか |
| --- | --- | --- |
| `45ca9073` | 「しなの」3Dモデル利用規約 (override 無し) | 参照レコード。属性の並び・条項の引用・原文への導線 |
| `18de8a92` | RadDollV3 利用規約 (2 行を横断 override) | 実効値層と行字義の分離 |
| `05b9a571` | — | 表示語彙 |
| `bfffa7aa` | — | item 固有条項が共有 terms に畳み込まれないこと |

## 凍結コピーであることの含意 (重要)

**このディレクトリでコーパス全件の適合テストを書かないこと。**

「新しいレコードが出た時にクライアントが黙って劣化していないか」を測るテストは、
コーパスが**増える側**にしか置けない。凍結コピーに対して全件テストを書くと、緑は保たれるが
**赤くなる事由が構造的に発生しない** — 検証しているように見えて何も検証していない状態になる。

コーパス全件の適合 (`EverySeedRecordParses…` / `EverySeedRecordShowsAllSevenAttributes…`) は
収載レコードを生成する側が、生きたコーパスに対して回す。

## 更新するとき

スキーマが変わってこの 4 本の形が古くなったら、配信中の現物で差し替える。
差し替えは「テストを緑にするため」ではなく「現物に合わせるため」に行う。
