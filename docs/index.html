MizEye

やさしい規約ビューア — VPM リポジトリ

VRChat 向け商品の利用規約を Unity 上で確認するためのビューアです。 署名付きの公開フィードを読み取る read-only のツールで、プロジェクトを一切変更しません。

VCC に追加する

  1. VCC の Settings > Packages > Add Repository に次の URL を追加します https://mizprism.github.io/mizeye/index.json
  2. プロジェクトの Manage Project から MizEye を Add します
  3. Unity で Window > MIZPRISM > MizEye を開きます

v0.1 の範囲

アバター素体を中心とした動作テスト版です。網羅性は主張しません。 未収載の商品は「未収載」と表示し、推測で埋めることはしません。 返すのは整理であって判定ではなく、最終的な判断と責任は利用者にあります。 対応 Unity は 2022.3。導入手順は VCC (Windows) を前提にしています。
